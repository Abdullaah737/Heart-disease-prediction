# Heart Disease Prediction

This project applies machine learning techniques to predict the presence of heart disease based on clinical and demographic data.

## Project Structure

- **data/**  
  Contains the dataset used for analysis and modeling:
  - `heart.csv`

- **notebooks/**  
  Jupyter notebook for data exploration, preprocessing, model training, and evaluation:
  - `Heart disease model.ipynb`

- **reports/**  
  Project reports and supporting documents:
  - `hea.docx` — Main project report
## Dataset

The dataset includes features such as age, sex, chest pain type, resting blood pressure, cholesterol, fasting blood sugar, resting ECG, maximum heart rate, exercise-induced angina, ST depression, slope, number of major vessels, thalassemia, and the target variable indicating heart disease presence.

## Getting Started

1. **Clone the repository**
2. **Install dependencies**  
   Recommended:
   ```bash
   pip install pandas scikit-learn matplotlib seaborn jupyter
   ```
3. **Run the notebook**  
   Open `notebooks/Heart disease model.ipynb` in Jupyter and follow the instructions.

## Results

The notebook explores various machine learning models, evaluates their performance, and provides insights into the most important features for heart disease prediction.  
See the `reports/` folder for detailed analysis and results.
